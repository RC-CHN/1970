# 1970

A small experiment with Git commit timestamps and GitHub contribution history.

This repository was created in 2026. Its initial commit intentionally sets both
`GIT_AUTHOR_DATE` and `GIT_COMMITTER_DATE` to `1970-01-01T12:00:00+00:00`.
The historical timestamp is only a demonstration, not the actual creation date.

Inspired by:
https://xuemeijing.github.io/2023/04/09/2023-04-09-change-your-github-contribution-history-to-1969/
